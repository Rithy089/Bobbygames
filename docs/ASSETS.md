# Original artwork and licenses

Game covers generated specifically for BobbyGames using the built-in image generation tool on 2026-09-06. No copied portal assets, commercial characters, flags, or business logos. Original fantasy tower is not a depiction of Angkor Wat.

Shared prompt: Landscape 3:2 premium playful low-poly 3D illustration, clear silhouettes, rich color, polished tactile game diorama, soft bevels, elegant faceted geometry, cinematic illumination, readable central composition. No text, letters, numbers, UI, logos, watermarks, flags or borders.

- Mango Catch: basket overflowing golden mangoes, a few floating above; lush Cambodian countryside rice fields and palms; golden sunshine, teal greens.
- Temple Tower: fictional decorated sandstone blocks stacked playfully offset over a violet-pink sunset landscape; Khmer-inspired geometric detailing; no sacred icons, not an exact depiction of Angkor Wat.
- Tuk-Tuk Rush: turquoise/yellow tuk-tuk on stylized Phnom Penh-inspired street; shops with blank awnings and palms; orange-coral atmosphere; no actual businesses.

Final project assets: public/art/{mango-catch,temple-tower,tuk-tuk-rush}-{480,960}.webp. Lossy WebP resized with Sharp; no external network assets at runtime.

Gameplay: original programmatic Canvas sprites, geometry and synthesized Web Audio tones, created for this project. Decorative culture icons: Lucide (ISC). Fonts: Inter and Noto Sans Khmer, self-hosted via Fontsource (SIL Open Font License). Library license files are retained in installed packages; full asset licensing inventory is in the lockfile and package license metadata. No copyrighted recorded music.

Culture facts (reviewed 2026-09-06): UNESCO World Heritage Angkor (https://whc.unesco.org/en/list/668/), UNESCO Tonlé Sap Biosphere Reserve (https://www.unesco.org/en/mab/tonle-sap), Royal Ballet (https://ich.unesco.org/en/RL/royal-ballet-of-cambodia-00060), Sbek Thom (https://ich.unesco.org/en/RL/sbek-thom-khmer-shadow-theatre-00108). Facts and Khmer drafts are structured in src/lib/culture.ts. Illustrations are decorative rather than historical reconstructions.
